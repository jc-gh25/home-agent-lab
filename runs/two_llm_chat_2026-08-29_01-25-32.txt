=== Round 2 — Participant A (ministral-3-14b-instruct-2512-som-mpoa) ===
For **Astro + GitHub Pages**, here’s a minimal structure to deploy in <15 minutes:

```
your-repo/
├── src/                  # Root content lives here
│   ├── pages/            # *.astro files → routes (e.g., index.astro = /)
│   │   └── index.astro    # Front page: `<h1>Welcome</h1>`
│   ├── styles/           # Global CSS (Tailwind or custom)
│   └── assets/           # Images, fonts
├── .github/workflows/   # GitHub Actions deploy
└── astro.config.mjs      # Config file:
     export default defineConfig({
       output: 'sitemap',
       site: { src: '/' }  // Auto-generates sitemap.xml
     })
```

**One-click setup**:
1. Install Astro CLI via `npm install -g astro@latest`
2. Create repo and run `astro new .` (yes, `.`)
3. Add GitHub Pages action:
   ```yaml
   # .github/workflows/gh-pages.yml
   name: Build + Deploy
   on: push
   jobs:
     build:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
           with:
             fetch-depth: 1
         - run: npm install && npx astro build --site src/
         - uses: action/gh-pages@6th-fw-action-v0.9.3-0 # Push to `src` branch
   ```
**Tradeoff**: Static sites work best for content-heavy pages with few dynamic interactions (e.g., filters, user auth). For interactivity, add a **serverless function** via [Vercado](https://verca.do/) or Netlify Functions.

**Critical gotchas I've seen others hit:**
- **Relative imports**: Astro uses relative paths by default (`import { something } from '../utils'`). Don't use absolute `/imports/...`.
- **Sitemap location**: It lives at `dist/sitemap.xml` after build — not in the root. GitHub Pages needs to know about it explicitly if using a custom domain + CNAME file.
- **Images**: Astro's `<img>` component handles resizing automatically, but you must use `.astro` syntax:

  ```astro
  ---
  import img from '../assets/hero.jpg';
  const width = Math.min(img.width * (500 / img.height), 1280);
  const height = Math.min(768, Math.floor(width * (img.height / img.width)));
  ---

  <figure>
    {`<picture>`}
      `<source srcset="{src: import.meta.env.BASE_URL}{url}, sizes=(max-width: 500px) 1280px"` />
      `<source srcset="{src: import.meta.env.BASE_URL}{url}", sizes="(max-width: 768px) 1280px, (min-width: 769px) calc(100vw - 4rem)"` />
    `</picture>`}
    <img {width}, {height}, class="rounded-lg shadow-md" src={url} alt="" loading="lazy">
  </figure>
  ```
